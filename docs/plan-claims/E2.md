# E2 · PCF AI assist (claim)

Spec: `docs/pcf/foundation/E2-ai-assist/CLAUDE.md`.

Plan (PRs into `redesign/integration`):

1. `[E2 1/3]` `POST /v1/pcf/material-factors/parse-excel`: read any layout of a
   material-factor spreadsheet into MaterialFactor-shaped rows (name, region,
   unit, kgCO2e per unit, source, year), each with `confidence` and `reason`.
   Header heuristics first, LLM column mapping when headers don't match.
   Units normalised with the invoice unit tables; an unknown unit is a warning.
2. `[E2 2/3]` `POST /v1/pcf/parse-bom` (xlsx/csv/pdf → lines {material, qty,
   unit, per declared unit}) and `POST /v1/pcf/match-factors` (suggest
   MaterialFactor ids with confidence and reason). Raw file stored as evidence.
3. `[E2 3/3]` FE: wire C04 Import and C02 "Import BOM" to these endpoints.

All endpoints require sign-in the same way python_AI_service #20 does.
`parse-declaration` is phase 3 (C06) and not in E2.
